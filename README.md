# YZM2031 - Data Structures and Algorithms | Fall 2026

Practice code and related learning materials for the course.

## Required Resources
- Main Textbook: Weiss, Mark Allen. Data structures and algorithm analysis in C++, 2022.
- Secondary book: Walter, J. Savitch. Problem Solving with C++, 10th Edition, 2018.
- Algorithm Visualization: https://visualgo.net, https://www.cs.usfca.edu/~galles/visualization/
- C++ Reference: 
	- www.cplusplus.com (C++11)
	- https://en.cppreference.com/
- Command line reference: https://ss64.com

## Suggested IDEs

Use any of the following environments for compiling, running, and debugging C++:
- **Visual Studio Code (VS Code)** — recommended for the course; available on Windows, macOS, and Linux
- **Code::Blocks** — lightweight, beginner-friendly C++ IDE
- **Xcode** — recommended for students using macOS
